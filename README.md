## Who Should Take It?

PL-900 is suitable for learners who want to understand how Power Platform supports business applications, data management, automation, and AI-powered agents. Previous development experience is not required, although familiarity with business processes and basic data concepts is helpful.

## Detailed Study Notes

### Power Platform business value

Microsoft Power Platform provides tools for building apps, automating processes, analyzing data, managing business data, and creating agents. Learn which product addresses each business need.

### Dataverse and environments

- Dataverse stores business data in tables with columns and relationships.
- Forms and views help users interact with records.
- Business logic can enforce rules and calculations.
- Environments separate apps, data, and resources.
- Governance includes access controls, privacy, monitoring, and lifecycle management.

### Power Apps

- **Canvas apps:** Flexible layout and user-interface design.
- **Model-driven apps:** Data-first applications based on Dataverse.
- **Code apps:** Extend application development with code-based approaches.
- Understand AI-assisted app creation and the purpose of Plan designer.

### Power Automate

Cloud flows automate online services; desktop flows support desktop and robotic process automation scenarios. Understand triggers, actions, connectors, conditions, approvals, and how to test a flow.

### Copilot Studio

Learn how agents use topics, knowledge sources, tools, and agent flows. Understand publishing channels, monitoring, evaluations, and responsible use of generative AI.

## Practical Examples / Labs

Use a trial or authorized Power Platform environment where available.

1. Create a simple canvas app for tracking tasks.
2. Explore a model-driven app backed by Dataverse.
3. Create a table with columns and relationships.
4. Build a cloud flow that sends an email when a form is submitted.
5. Configure an approval flow and test its outcomes.
6. Explore Copilot Studio by creating a simple agent with a knowledge source.
7. Review environment roles and compare development and production environments.

## Common Mistakes

- Confusing canvas apps with model-driven apps.
- Mixing up triggers and actions in flows.
- Ignoring Dataverse relationships and environment concepts.
- Memorizing product names without understanding use cases.
- Overlooking Copilot Studio objectives in the updated exam.
- Studying outdated objectives without checking the current guide.
